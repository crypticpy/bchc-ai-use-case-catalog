--- layout: default --- {%- comment -%} The catalog's directory, at //a-z/: every entry by name, and every facet value in use, each linking to its own landing page. It is the no-JavaScript browse path, the thing a crawler can walk, and the answer to a high-cardinality name-shaped facet (an "Organization" field renders as forty truncated pills in a 272px rail; here it is a list you can read). Generated by _plugins/facet_pages.rb — there is no file on disk, because the entry path is `_data/schema.yml`'s to choose. Both lists are computed once per build by that plugin: `site.data.entry_az` groups the entries by first letter, `site.data.facet_index` describes the generated landing pages. With landing pages switched off (`landing.enabled: false` in _data/search.yml) the tag half disappears and the A–Z list stands on its own. No field key is named anywhere below.
