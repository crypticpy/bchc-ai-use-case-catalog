# BCHC AI Use Case Catalog support

The BCHC AI Use Case Catalog is a BCHC deployment of community-maintained PHCT software, supplied
under the MIT license and without warranty.

- Search existing issues and documentation before opening a report.
- Use the structured bug, accessibility, or feature issue form and include a public reproduction.
- Do not put credentials, personal information, protected health information, non-public URLs, or
  security details in a public issue. Follow `SECURITY.md` for private vulnerability reports and
  `docs/incidents.md` for urgent published-content takedowns.
- Maintainers aim to triage ordinary reports within five working days when capacity permits. This
  is a target, not a service-level agreement.
- BCHC-specific content, policy, branding, DNS, publication, and GitHub organization access remain
  the BCHC owner's responsibility. A reusable software defect should be reproduced in PHCT and
  fixed there before the released update is consumed by this repository.

When reporting a defect, state the exact PHCT release/commit, browser or runner, expected behavior,
actual behavior, smallest reproduction, and whether the problem affects an accessibility,
security, submission, publication, update, or rollback path.
