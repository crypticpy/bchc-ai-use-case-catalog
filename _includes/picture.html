Derivatives come from `_data/derivatives.json`, written by `npm run images` (scripts/derive_images.mjs) and committed with the screenshot they belong to. **No manifest entry means exactly today's plain ** — an external URL, an image a maintainer dropped in by hand, and a fresh fork that has never run the script all still render. The manifest is an optimisation, never a requirement, so nothing here may become load-bearing for the page to work. Every variant is confirmed on disk with `static_file` before it goes into a srcset. A that matches by type and then 404s is NOT retried against the — the reader gets a broken image — so a manifest that has drifted from the tree (a hand-deleted file, a half-resolved merge) has to degrade to the original rather than to nothing. The check is a memoised Set lookup, not a scan.
