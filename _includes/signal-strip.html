{%- comment -%} Signal strip: the `card: icon` fields of one entry as icon + short-label glyphs. Shared by entry-card.html and entry-row.html so both stay in step. Usage: {% include signal-strip.html entry=entry class='signal-strip' %} Params: entry (required); class (optional, wrapper classes — defaults to "signal-strip"). Renders nothing when the entry has no signal values. Cap (design-brief.md → Catalog card): at most FOUR items including one trailing "+n". `ss_total` is every value across the icon fields; `ss_cands` is what the per-field cap of 2 would let through. As soon as anything has to be hidden the glyph budget drops to 3, and n = ss_total - glyphs shown — ONE counter for the whole strip rather than one per field.
